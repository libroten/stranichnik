# Stranichnik.DevResetSync

Тестовая утилита для ручных прогонов конфликтов WebDAV-синхронизации.

Что делает:

1. Читает текущие настройки приложения.
2. Забирает WebDAV URL, имя пользователя и сохраненный пароль через штатное хранилище credentials.
3. Удаляет все содержимое настроенного WebDAV-каталога, но не сам каталог.
4. Очищает локальные данные приложения.
5. Создает новый `settings.json`, оставляя только WebDAV-настройки.
6. Запускает приложение с `--print-logs-to-console`.

Утилита намеренно не печатает URL, имя пользователя, пароль и имена удаленных remote-файлов.

Запуск:

```bash
dotnet run --project Tools/Stranichnik.DevResetSync
```

Только reset без запуска приложения:

```bash
dotnet run --project Tools/Stranichnik.DevResetSync -- --skip-launch
```

Защита от случайного удаления корня: WebDAV URL обязан указывать на непустой путь, например на отдельный тестовый каталог.
